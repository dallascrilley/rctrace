What this output can and cannot tell you

--announce_rc reports options read from rc files. RcTrace keeps each recognized option with the source Bazel announced. It does not calculate the final effective value, resolve config precedence, inspect command-line overrides, or diagnose a cache miss.

Option explanations link to Bazel documentation. Repository download caching is shown separately from action caching. Action-configuration options are described as possible influences because their effect depends on the configured targets.
